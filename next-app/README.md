- layout.tsx: Rahmen, der für alle Pages und Unterpages gilt
- page.tsx: Die Seitenkompontente selbst, standardmäßig eine Server Komponente

- loading.tsx: Loading Indicator
- not-found.tsx: Not Found Page
- error.tsx: Fehlerseite

# Components

- Server Components als Standard
- Server Components können async sein
- haben keinen State
- haben keinene Lifecycle
- haben keine User Interaktion
- Voller Zugriff auf Node.js inclusive fetch
